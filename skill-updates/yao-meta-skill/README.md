# 技能工坊：人工评分流程更新

这是对既有 `yao-meta-skill` 的增量更新包，不是另一个可独立安装的技能。保留既有执行脚本和资源，只替换同名文件并增加人工评分方法及模板。当前完整来源为 `~/.codex/skills/yao-meta-skill`，Skills Manager 的现有条目名称为“技能工坊”。

本轮聚焦：每次迭代实际执行、按任务选择 3–5 个可观察标准、选项评分、复制纯文本回聊天、核心项优先和人工待评状态。允许旧新版并存，也尊重用户要求的原位替换。

入口：[主技能](SKILL.md)、[人工评测方法](references/human-evaluation.md)、[可复用评分页](assets/human-scorecard.html)。模板默认是示例，必须填入实际成果；不能拿模板文字冒充执行证据。

本轮按用户要求直接更新原技能；人工验收为单版本、一个流程，尚未收到用户评分，不声称已通过或优于旧版。实际评测目录被仓库忽略，通用更新不附带用户评测材料。

技术验证与已知限制见 [VALIDATION.md](VALIDATION.md)。恢复与部署事实见 [HANDOFF.md](HANDOFF.md)。

2026-11-14追加用户修正：图片评分必须限尺寸左图、右侧评分，同一界面看图打分；候选用编号或上一张/下一张切换，不再上下滚动寻找评分。已更新通用模板、完整技能来源与刺绣技能模板。新布局技术检查通过，尚未把它写成人工已接受。
