## 设计验收映射

1. **代码即产物**：完整零依赖 HTML 模板和成品样例；静态预检可阻止缺失组件、外链与网络调用。
2. **认知粒度**：每轮一个可预测的微型因果闭环；样例只解释“增长算在当前总量上”。
3. **公平冲突**：预测正确时承认，错误时固定其他条件做对照，不使用藏条件的反转。
4. **唯一第一锚**：按忠实度、瓶颈、可操作性、熟悉度裁决；允许同一模型的辅助视图。
5. **装配/涌现双模**：确定性装配与局部规则到宏观系统分别路由；随机比较须控制种子。
6. **闭卷守门**：页面遮蔽前文，聊天模型依据理由判卷，错误时输出微型可运行反例。

下一轮验证应在允许访问本地文件的浏览器环境里检查真实渲染和键盘操作，再用至少一个确定性主题与一个 agent 主题进行完整多轮模型试用；这些是未取得的证据，不计入本次通过项。
