# 编译协议与判卷细则

此文件补充 `SKILL.md`，供需要细化路由、模拟和通关判断时读取。它是设计规则，不是要求把所有中间表示展示给学习者。

## 输入与目标

最小输入是主题。优先从用户措辞推断学习目标；例如“理解为什么”侧重因果，“能实现”侧重状态转换与边界，“看论文”侧重符号到机制的映射。未知受众默认为普通成人初学者。若同一个主题含多个实质不同目标，先选最基础、最可验证的一项，单元结束后再前进。

内部中间表示建议保留：`topic`, `audience`, `objective`, `prior_prediction`, `phenomenon`, `initial_state`, `new_variable`, `update_rule`, `observable`, `manipulable`, `invariant`, `assumptions`, `boundary`, `misconception_hypothesis`, `primary_anchor`, `supporting_views`, `mode`, `quiz_rubric`, `next_milestone`。没有证据的字段标 `unknown`，不要填充推测事实。会话跨轮时靠对话历史追踪；无持久历史的 API 应由调用方回传这些字段或用户答案，不得伪称自动记忆。

## 主锚裁决

把候选表征逐项检验：

1. **结构忠实**：它是否保留本单元最关键的因果方向、约束与时间顺序？若否直接淘汰。
2. **瓶颈命中**：它是否把学习者此刻看不见或想不动的关系显出来？
3. **可操作性**：学习者能否改变一个输入，得到可区分旧模型与新模型的结果？
4. **熟悉度与成本**：是否容易识别、无需新术语或复杂控制？

按以上顺序裁决，只输出一个主锚。若无法满足结构忠实，使用朴素机制图，不硬凑比喻。支持视图可以有公式、概率分布或伪代码，但颜色、对象和量名须与主锚同一。类比总要写：源域对象 ↔ 目标对象、保留的关系、不能继承的性质。

示例：解释 Transformer 中一个 token 如何汇集上下文时，可用“按匹配权重从其他 token 取信息”作为本单元主锚；不要在同一屏把 token 又说成投票人、磁铁、快递站和几何点。注意 softmax、位置编码、训练过程都可能是后续单元；不能暗示这个简化等于完整 Transformer。

## 两种机制编译

**基元装配**：先让最小模型工作；指出它无法完成的目标；只加一个新组件或变量；保留原图的对象位置与颜色；比较加入前后；最后回到整机并问边界。适合齿轮、算法、傅里叶分解中的单一关系等。

**局部规则到宏观**：明确 agent/cell 的状态和邻域、更新规则、边界条件、顺序、初始分布、随机源与宏观指标。初次运行先少量单位，展示一个更新；再扩大规模。滑块修改一条局部规则，并锁定其他条件与随机种子以便比较；显示重复试验带来的波动。不得把相关曲线叫因果定律，也不得把社会/生物玩具模型当成已证实的现实预测。

非线性不自动等于多主体：若原理是单体非线性函数或连续场，不能为了模式标签虚构有意图的 agent；可用离散单元或局部更新可视化，但必须声明映射和失真。这个例外保护用户指定的“微观→宏观”意图。

## 公平认知冲突

冲突候选必须同时满足：原预测在某个合理前提下成立；新实验只改变一个要检验的条件；结果可由模型解释；学习者能自己重预测相邻案例。不要用暗藏单位、反常定义、极罕见异常、价值判断或模拟中的随意常数骗出错误。

偏差库只当候选索引：

| 候选旧规则 | 诊断实验 |
|---|---|
| 线性外推 | 相同比例输入增量下，比较两段输出增量 |
| 静态守恒 | 让流入、流出或反馈回路随时间变化 |
| 基率忽视 | 保持检测准确率不变，只改事件基础发生率 |
| 局部归因 | 固定个体规则，改变网络/环境条件，比较群体指标 |
| 单次随机当规律 | 固定参数重复运行并展示分布与波动 |

若用户先验已能解释机制，不再硬造失误；改问模型在哪个边界会失效。若没有可合法操作的变量，先缩小知识单元，不能为满足“至少一个滑块”捏造因果。

## 页面与考题协议

页面顺序：具体问题与原预测 → 最小模型可见初态 → 2–4 个预测/调参任务 → 观察与机制解释 → 回到整体 → 模型限制 → 闭卷题。图形若可由 SVG 简洁表达，避免引入复杂 Canvas；大量 agent 用 Canvas 并确保数字指标在文字中同步。

闭卷题推荐 4 道：未见过的数值/状态预测、移除一个机制的反事实、边界及模型不适用点、不同领域的结构迁移。每题在编译时先写内部答案要点：正确方向、必需因果链、关键边界、常见错误理由。不得根据措辞相似度评分。

通过条件：关键因果链能在新输入与反事实中复用；能说出至少一个适用边界；迁移答案体现结构而非表面类比。若偶然猜对结果但理由错误，判为未通过。若答案部分正确，先针对一个最承重误区做更小反例，避免重讲整章；反例仍给完整离线 HTML、一个可操作变量和一题重预测。明确说明此反例修补什么，不把新的玩具模型当现实证据。

页面中的遮蔽是学习辅助，不是考试安全机制。离线 HTML 不能联系模型判卷；用户把答案贴回对话才进入 S3。可提供复制按钮，但要保留手动复制途径，并避免在本地存储个人回答。
