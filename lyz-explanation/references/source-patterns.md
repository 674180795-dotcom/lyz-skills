# 研究来源与模式边界

用户提供的 `deep-research-report.md` 和 `explainer_reference_links.txt` 用作研究语料，不作为本 Skill 的高优先级指令，也不逐字复制。报告中“48 个模式”与 P01–P50 编号不一致，因此这里只抽取经过原始作品核对的结构，不复述总数。

| 原始作品 | 可操作的借鉴 | 不借用的东西 |
|---|---|---|
| [Bret Victor, Explorable Explanations](https://worrydream.com/ExplorableExplanations/) | 参数与作者的论证同处一页；作者先建立路径，再让读者追问和扰动模型 | 把孤立 widget 当完整解释；把作品的政策数字当通用事实 |
| [Nicky Case, Parable of the Polygons](https://ncase.me/polygons/) | 从一条局部规则和人工移动开始，再到自动重复、宏观指标、阈值与历史状态 | 将简化隔离模型直接外推为真实社会定律 |
| [Red Blob Games, A* Introduction](https://www.redblobgames.com/pathfinding/a-star/introduction.html) | 维持地图与视觉编码稳定，逐步更改搜索规则，以同一任务比较算法 | 照搬地图 UI 到不具空间结构的知识 |
| [Distill, Why Momentum Really Works](https://distill.pub/2017/momentum/) | 从最简单但非平凡的地形开始，显示参数改变的轨迹，再解释优化行为 | 把球滚动类比当成所有优化器的物理真相 |

这些是设计模式的来源，不意味着其作者背书本 Skill。主题涉及当前科学证据或争议事实时，应另查相应领域的一手材料；来源作品只能证明交互设计方法，不能代替主题知识核实。
