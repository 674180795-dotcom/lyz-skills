# 航空刺绣设计 1.1

独立技能标识：`lyz-aircraft-embroidery-v1-1`，版本1.1.0。原版 `$lyz-aircraft-embroidery` 保留，不覆盖、不更新。

本轮针对用户指出的结构、省略、颜色、角度和文字问题重新对照本地35张样本（32张唯一文件），目标是生成能放进同款产品系列的图片。变化不是另写几个故事：参考图负责机体的大形省略、投影、色块、型号字的位置/字形和绣边组织，不能只传针线质感。

```text
使用 $lyz-aircraft-embroidery-v1-1，参考上传的刺绣章系列，
设计一枚J-20扩款，保留同系列的视觉省略、色块和型号文字，直接生成产品图。
```

## 核心规则

型号保真 > 参数正交 > 变体多样性。同系列审美是FBS预期行为的一部分，不是可随意丢掉的装饰。

- 机体保留识别点，以少量大色面表达；减少微小面板与铆钉，不把所有边都描成奶白浮雕。
- 默认浅斜机背3/4，核对近远翼的投影；不把“3/4”当一个没有图形约束的风格标签。
- 型号文字在构图开始就占位置，默认是显眼的图形锚点；用户明确不要文字时才能为空。
- 四个家族按样本关系组织：kinetic_grid、cloud_ink、red_charge、night_contrast。不同家族有不同主色面积、字形和色面节奏，不能全变成海军蓝加金色。
- 网格与斜向机体可以共存；没有实际冲突就不删掉关键参考特征。窄平绣边承接章体，避免粗绳圈框架。

完整证据与理论落地见 [系列语法](references/series-grammar.md)。比例是视觉设计起点，不是逐像素标注或工厂针版。

## 使用与依赖

```bash
python3 scripts/compile_prompt.py assets/example-brief.json --out output/my-job
python3 -m unittest discover -s evals -p 'test_*.py' -v
```

编译器只需要Python标准库，输出prompt.txt、design.json、request.json；它不生图。宿主Agent读取提示，逐张查看参考，再实际调用当前可用的内置image_gen工具，见 [执行规则](references/workflow.md)。工具不可用时明确报告未生成，不静默切付费模型。

内置J-20/J-35A粗外形卡；新型号先取得可靠外形证据再传verified subject_card，禁止近似替换。本技能不交付机绣针版、不认证生产可行性，不做军事性能分析。
