# 航空刺绣设计 1.1.5

独立标识lyz-aircraft-embroidery-v1-1，原始lyz-aircraft-embroidery不变。本版重心是飞机保原样的刺绣化简化，以及飞机、背景、字体的逻辑呼应。未来评测统一使用用户上传多视图中的J20，不再换型号做设计评分。

整套35张图是产品语言资料库，去重为32份视觉来源，含不同子系列。归纳共同的简化、色块、字形重量和针线组织，不把它们硬套为一种配色，也不为每款绑定两张风格供体。本轮以覆盖全库的三张总览与用户J20图作为两版相同的四份输入。

设计先有一个场景或行动，再让背景解释飞机动势，字形切角、基线、配色与翼线和留白呼应。composition/motif/lettering是联动记录；不是随机拼装的三个独立素材。飞机合并为4–6个宽色块和少量识别标记，保比例，不把写实机体简单加线纹。仅交效果图，不认证生产针版或工艺可行性。
