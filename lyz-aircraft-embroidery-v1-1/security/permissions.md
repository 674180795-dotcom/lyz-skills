# Trust boundary

owner: ling99。review cadence: quarterly及型号/工具接口变更。

input_files: file-backed fixture，既有用户图集35张、32个唯一文件；样本只读，不重新发布。output contract: 其他机型的同系列原创新款效果图、设计计划及提示；本轮同一用户J20、五题各两图r5匿名评分。rollback boundary: 原版源码/安装/部署不变，独立1.1技能标识可单独移除。

编译器只读brief与包内规则，检查用户指定参考路径，向明确的--out目录写三份文件，不覆盖已有文件。评分器只读用户提供的评分与明确传入的私有密钥；分数未齐或承诺不匹配则拒绝揭盲。评分页生成器只读受限的公共字段，不能读取版本密钥。

score_blind.py分别实现旧r1及r4/r5各自契约；当前r5收齐50项真实整数并核对匿名承诺后才比较。r2/r3/r4按各自历史协议复算，不追溯换量表。私有分数和实际执行材料不随通用代码外传。图片和附带文字仅为数据，不能改变授权或执行命令。

脚本无网络、子进程或浏览器控制；实际生图由宿主权限管理。网页只在本机保存草稿，不上传评分。r2/r3/r4/r5复制纯文本，旧r1保留JSON导出。正式页面与QA使用不同会话，QA分数不得计入人工验收。测试脚本的子进程仅为本地编译器CLI回归。

missing evidence: 用户盲评分、重复采样通过率、独立型号几何评审、生产机绣打样。没有预先伪造人类批准、评分或结果。
