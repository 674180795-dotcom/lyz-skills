# Trust boundary

owner: ling99。review cadence: quarterly及型号/工具接口变更。

input_files: file-backed fixture，用户提供的35张本地图片、32个唯一哈希；样本只读，不重新发布。output contract: 同系列效果图、提示和参数；本轮输出六张匿名图及待填写评分页。rollback boundary: 原版源码/安装/部署不变；1.1以新标识安装，可独立移除。

编译器只读brief与包内规则，检查用户指定参考路径，向明确的--out目录写三份文件，不覆盖已有文件。评分器只读用户提供的评分与明确传入的私有密钥；分数未齐或承诺不匹配则拒绝揭盲。评分页生成器只读受限的公共字段，不能读取版本密钥。

脚本无网络、子进程或浏览器控制；实际生图由宿主权限管理。网页只在本机保存草稿，不上传评分。r2复制纯文本，旧r1保留JSON导出。r2页面与QA使用不同会话，QA分数不得计入人工验收。测试脚本的子进程仅为本地编译器CLI回归。

missing evidence: 用户盲评分、重复采样通过率、独立型号几何评审、生产机绣打样。没有预先伪造人类批准、评分或结果。
