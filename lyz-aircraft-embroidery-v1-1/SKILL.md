# 航空刺绣设计 1.1

目标是**保原样的刺绣化简化、飞机/背景/字体呼应、系列感与审美**。机型一致性是输入前提和执行检查，不把翼尾计数当成核心设计分数。先读[设计规则](references/design-expansion.md)和[执行规则](references/workflow.md)。

## Workflow

1. 查看整套样本并去重，区分章内设计和外部海报。样本有不同子系列，先提炼共同的图形省略、色块、字形重量与针线语言，再选适用关系；不硬说所有样本是同一配色模板，不为每款指定两张风格供体。可用覆盖全库的总览作为series输入，勿裁掉信息或漏算来源。
2. 锁定用户指定飞机及参考。未来测试统一使用用户上传多视图中的J20，默认J-20；未经明确变更不换型号或另画粗结构示意替代上传图。保留机体比例与识别点，合并伪装、蒙皮、铆钉等细节为清楚大形。geometry不提供背景、海报标签或迷彩模板。
3. 按设计参数树锁定主体，先确定一个场景或行动，再联动飞机姿态、背景动势/正负形、字体切角/基线/配色。design_plan的composition/motif/lettering是同一意图的三项记录，不是独立抽签的装饰。填brief，运行 `python3 scripts/compile_prompt.py brief.json --out output/<job>`。
4. 逐张看将传入的参考，用内置image_gen真实生成。最多一张geometry、三张series总览；不要复制任何一张成品布局。飞机以4–6个宽色块和少量识别标记表达，减少细线、碎岛与逐条描缝；这不是生产针版认证。
5. 检查刺绣化简化、图文呼应、同系列感、整体审美、原创设计。对照上传飞机确认一致性，但不以部件计数代替设计判断。保留首图及问题，不自签用户接受。

每轮固定旧新各5张、共10张，按[评测契约](references/blind-eval.md)新开r5。生成顺序与盲测呈现顺序分开记录：生成按原任务流程；盲测随机打散，同题两张之间至少隔两张其他图，页面和复制文本只显示A–J，不暴露配对任务名或版本。收齐50项真实分数后才揭盲。

当前1.1.5对照冻结1.1.4，状态pending_human；旧r1–r4仅作历史。原始独立技能源码、库与部署不变。评分页限尺寸左图、右侧五项同屏，说明和放大图用弹窗，候选原位切换。实际素材、图片、评分和执行材料仅留本机，不入Git或代码ZIP。无内置工具则说明未生图，不暗换API。assets/rules.json中的旧fbs_lexicon是历史解释资料，不覆盖当前priority或r5标准。
