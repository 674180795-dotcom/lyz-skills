# 排版示例

以下只是格式示例，不能当作本次素材的发言来源。

```markdown
# 有原文依据的文章标题

简短导语。必要时说明据提供的访谈转录整理，未知日期不补造。

## 一个必要的主题

**好奇：原访谈中确实问过的问题？**

**回答：** 第一段回答，保留原话的意思和语气。

这是同一次回答的续段，直接续写，不加任何身份标签。

**好奇：原有追问？**

**回答：** 新回答从这里开始。
```

不要写“问”“嘉宾”，不要每段重复“回答”。多人首次回答及换人时写 `**回答（姓名）：**`，同一人续段仍直接写正文。连续回答段可以有很长一段，不为插入问题而编造主持人发问。

默认最终目录只有文章文件。校勘过程留在系统临时会话，成功交付后删除；用户明确要求审计或保留过程时另行保留。
