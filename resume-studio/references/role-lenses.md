# 岗位镜头

岗位镜头是一组提问与证据分类工具，不是关键词填充器。用户提供 JD 时以 JD 为准；没有 JD 时，只用对应镜头识别可能遗漏的证据。

| 岗位族 | 优先寻找的真实证据 | 可帮助回忆的问题 |
|---|---|---|
| 软件 / AI / 数据 | 系统范围、技术决策、质量、性能、可靠性、测试、部署、数据口径 | 你独立做了哪一层？最难的技术取舍是什么？如何验证可用？ |
| 产品 | 用户问题、需求判断、优先级、方案取舍、实验、上线与采用 | 谁遇到什么问题？你做了哪个决策？什么反馈改变了方案？ |
| 运营 / 增长 | 人群、渠道、漏斗、活动、流程、留存、转化、效率 | 你改变了哪个环节？接手前后有什么可观察变化？ |
| 市场 / 内容 | 受众、定位、创意、内容资产、渠道、触达、线索、品牌一致性 | 内容给谁看？你负责策略还是执行？结果如何被观察？ |
| 设计 / 研究 | 问题定义、用户研究、约束、迭代、设计系统、交付与采用 | 哪个洞察改变了设计？你如何验证？最终被谁使用？ |
| 销售 / 客户成功 | 客户分层、商机、方案、周期、成交、续约、问题解决 | 你负责哪段客户旅程？结果属于个人还是团队？ |
| 咨询 / 金融 / 分析 | 问题拆解、模型、数据来源、假设、建议、决策影响、风险 | 你的分析改变了什么决策？关键假设如何验证？ |
| 人事 / 行政 / 项目管理 | 服务范围、流程、周期、成本、风险、跨团队协调、稳定交付 | 哪个流程由你建立或改进？减少了什么等待、错误或风险？ |

## 使用规则

1. 先读已有材料，再选一个岗位镜头；不要把整张表变成问卷。
2. 只追问会改变取材、排序或真实性判断的内容。
3. 术语必须来自用户实际工作或 JD；不知道时用普通话表达。
4. 常见指标只是回忆提示，不是默认事实。用户没有数据时不诱导估算。
5. 新岗位、公司动态或当前招聘要求可能变化；确需调研时优先官方招聘页和一手来源，并标明时间与来源。
