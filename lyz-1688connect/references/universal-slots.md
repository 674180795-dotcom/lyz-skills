# 10 大通用工业品类参数槽位规范 (Universal Slots Specification)

无论对接纺织品（织唛、刺绣、布贴）、金属五金（徽章、金属书签、钥匙扣）、塑料亚克力还是纸质包装，底层工业制造采购均抽象收敛为以下 10 个数据槽位。

---

## 📋 槽位全景矩阵

| 槽位代码 | 槽位名称 | 数据类型 | 级别 | 业务定义与提取准则 | 缺失处理动作 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `SLOT_FEASIBILITY` | **工艺可行性** | `bool` / `str` | **必填核心** | 厂家机台是否能做该款（能否复刻/需要改动什么）。识别“能做”、“做不了”、“可以”等信号。 | 强制催问（第一关卡） |
| `SLOT_PROCESS_SUGG`| **工艺建议** | `str` | 选填参考 | 厂家专业制造建议（如：“推荐织唛”、“建议数码印+绣边”）。用于触发规格漂移评估。 | 默认沿用初始方案 |
| `SLOT_UNIT_PRICE`  | **大货单价** | `float` | **必填核心** | 目标梯队数量（如 300/500/1000 套）的产品出厂裸价。严禁丢失小数点。 | 强制催问（核心决策项） |
| `SLOT_PACKAGING`   | **包材装配** | `float` / `str` | 关键成本 | 独立 OPP 袋、自封袋、背卡定制印刷及人工套袋装配费。防后期临时加价。 | 差量追问 |
| `SLOT_SHIPPING`    | **物流运费** | `bool` / `float`| 商业谈判 | 批量货重下的物流归属（是否包邮、快递费金额或发物流自提）。 | 差量追问 |
| `SLOT_SAMPLE_FEE`  | **打样/开版费** | `float` | **必填核心** | 产前样品费用（版费、刀模费、打样费）。如 `¥150/款`。 | 强制催问 |
| `SLOT_REFUND_RULE` | **退打样费** | `bool` / `str` | 商务谈判 | 后期大货订单达到多少数量/金额全额退还或冲抵货款。如“做满500退样费”。 | 差量追问 |
| `SLOT_TAX_POINT`   | **税票点数** | `float` | 合规核算 | 开具增值税普通发票（通常 1~3 点）或增值税专用发票（通常 13 点）加点要求。 | 差量追问 |
| `SLOT_LEAD_TIME`   | **大货交期** | `str` / `int` | **必填核心** | 从确认样品/图纸到大货出厂发货的天数或绝对承诺日。如“一周（7天）”。 | 强制催问（排期红线项） |
| `SLOT_CONTACT_INFO`| **脱媒联系方式** | `list[str]` | 高意向转化 | 厂家电话、微信（绿泡泡）或厂长联系方式。规避风控安全获取。 | 意向明确时反向引导 |

## 🔍 槽位提取与语义识别逻辑 (Extraction Logic)

### 1. `SLOT_FEASIBILITY`（工艺可行性）
- **正向触发词**：`能做`、`可以`、`没问题`、`做得了`、`在的老板`、`发来核对`；
- **负向触发词（触发熔断）**：`做不了`、`做不到`、`发不了`、`赶不上`、`做不了这个工艺`、`超长了`；
- **条件触发词（触发规格漂移）**：`要改`、`渐变色不行`、`太小了绣不了`、`精度不够`。

### 2. `SLOT_UNIT_PRICE`（大货单价）
- **高精度提取规则**：严格识别带小数点的数值，杜绝丢失角分位；
- **正则模式**：
  - `单价\s*([0-9.]+)\s*(左右|元)?`
  - `([0-9.]+)\s*(?:元|块)?(?:一个|每件|套|只|单价)`
  - `¥\s*([0-9.]+)`

### 3. `SLOT_SAMPLE_FEE`（打样费）
- **提取规则**：提取明确标注的版费或打样成本；
- **正则模式**：
  - `打样(?:费)?\s*([0-9.]+)\s*(每款|元)?`
  - `版费\s*([0-9.]+)\s*元`
  - `打版\s*([0-9.]+)\s*元`

### 4. `SLOT_LEAD_TIME`（大货交期）
- **提取规则**：提取工期天数、周数或具体日期；
- **正则模式**：
  - `(?:交货期|交期|大货交期|制作周期)\s*([一二三四五六七八九十0-9]+[天周月]+|一周)`
  - `([0-9]+)\s*天(?:左右)?`

### 5. `SLOT_CONTACT_INFO`（联系方式）
- **连续 11 位数字**：`1[3-9]\d{9}`；
- **防风控拆分气泡**：提取前 7 位 + 后 4 位的分段连续气泡（如 `1992410` 与 `6604` ➔ `19924106604`）；
- **微扰字符清洗**：清洗 `V同`、`微`、`电`、`—`、`·` 等混淆字符。

## 📈 槽位完成率计算公式 (Completion Metric)

系统将槽位分为 **必须项（Core Slots）** 与 **补充项（Secondary Slots）**：

- **Core Slots (权重 70%)**：
  - `SLOT_FEASIBILITY`
  - `SLOT_UNIT_PRICE`
  - `SLOT_SAMPLE_FEE`
  - `SLOT_LEAD_TIME`
- **Secondary Slots (权重 30%)**：
  - `SLOT_PACKAGING`
  - `SLOT_SHIPPING`
  - `SLOT_REFUND_RULE`
  - `SLOT_TAX_POINT`

$$CompletionRate = \frac{N_{CoreFilled}}{4} \times 0.7 + \frac{N_{SecondaryFilled}}{4} \times 0.3$$

- **状态判定准则**：
  - `CompletionRate >= 0.85` ➔ 判定为 `SlotsCompleted`，可直接结案；
  - `CompletionRate < 0.85` 且 `Rounds < 3` ➔ 提取未填槽位，进入 `FollowUpPrompt` 差量追问；
  - `Rounds >= 3` ➔ 终止追问，判定为 `PartiallyQuoted`。
