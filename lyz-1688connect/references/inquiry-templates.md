# 标准话术与追问模板库 (Inquiry Templates Library)

本规范收录了在 1688 移动端真机沟通中经过实战检验的契约化首发、差量精准追问、规格漂移重算与脱媒防风控话术模板。

---

## 🚀 一、 首发契约全量合发模板 (Contractual Inquiry)

### 1. 拟真分段发送标准模板 (推荐 · 4连发短气泡)
> 📌 **发送规约**：单条严格控制在 40 汉字以内，每条之间间隔 0.5~0.7 秒，模拟真人打字手速。

- **气泡 1（打招呼 + 认款认工艺）**：
  > `老板好，这款产品图片刚发您，贵厂机台能完全复刻吗？`
- **气泡 2（基本参数与数量）**：
  > `尺寸按{{DIMENSIONS}}，材质做{{MATERIAL_AND_CRAFT}}，首批做{{ORDER_QTY}}个。`
- **气泡 3（单价与包装明细）**：
  > `麻烦报下{{ORDER_QTY}}个出厂裸价？另外独立OPP袋+背卡装配人工费多少？`
- **气泡 4（打样、税票与交期）**：
  > `打样费多少？大货能退样费吗？加普票几个点？大货最快几天能发出？`

---

### 2. 全量一体化合发模板 (单气泡长约)
> 📌 **适用场景**：PC 千牛客服、或单次剪贴板大段粘贴下发。

```text
老板好，图片中的产品我们近期下单制作，以下为完整采购需求，麻烦一次性核对并逐条回复报价：

【基本参数】
1. 产品品类：{{PRODUCT_CATEGORY}}
2. 规格尺寸：{{DIMENSIONS}}
3. 材质工艺：{{MATERIAL_AND_CRAFT}}
4. 首批数量：{{ORDER_QTY}} 个

【请逐项报出以下 5 点明细，以便直接定单】：
1. 制作可行性：贵厂现有工艺能否完全复刻？有需调整之处请直言。
2. 拆解单价：产品裸价多少？背卡+独立OPP袋+人工装配费多少？
3. 运费与发票：{{ORDER_QTY}}个是否包邮（不包邮运费大概多少）？开具普票加几个税点？
4. 打样与减免：打样费用多少？做大货能否全额退还打样费？
5. 交期红线：能否确保 {{SHIP_DEADLINE_DATE}} 前大货发出？
```

## 🎯 二、 差量精准追问模板库 (Delta Follow-Up Library)

> ⚠️ **核心原则**：严禁重复提问厂家已答复的项目！每轮根据缺失的槽位集合 `missing_slots` 动态组合 1~2 句轻量问句。

### 1. 单价已答，缺失配套成本（包装、运费、税点）
- **组合追问话术**：
  > `“老板单价收到了！包装背卡加多少？{{ORDER_QTY}}个包邮吗？普票几个点麻烦也确认下哈”`

### 2. 单价已答，缺失样品与交期（打样费、退样规则、交期）
- **组合追问话术**：
  > `“收到！请问这款打样费是多少？后期大货做{{ORDER_QTY}}个能全额退样费吗？交期几天能出？”`

### 3. 工艺确认能做，未报任何价格
- **直接催价话术**：
  > `“能做太好了！请问{{ORDER_QTY}}个大货单价和打样费分别多少？我们今天综合核价定厂”`

### 4. 针对单一缺失槽位的原子化追问句 (Atomic Prompts)

| 缺失槽位 | 推荐原子追问句 |
| :--- | :--- |
| `SLOT_UNIT_PRICE` | `“老板，{{ORDER_QTY}}个的大货裸价是多少呢？”` |
| `SLOT_PACKAGING` | `“包装这块：如果加背卡印刷和独立自封袋，每套加多少钱？”` |
| `SLOT_SHIPPING` | `“这个量发江苏/广东包邮吗？不包邮运费大概多少？”` |
| `SLOT_SAMPLE_FEE` | `“产前打样费收多少？几天能出样？”` |
| `SLOT_REFUND_RULE` | `“大货如果定{{ORDER_QTY}}个，打样费可以冲抵大货款吗？”` |
| `SLOT_TAX_POINT` | `“我们需要开增值税普票，贵厂税点是加几个点？”` |
| `SLOT_LEAD_TIME` | `“排期方面，从定稿到大货发出总共需要几天？”` |

### 5. 超时已读不回 / 停滞催单话术
- **温和推进**：
  > `“老板在吗？这个项目排期比较紧，麻烦抽空核算一下上面标出来的几点，合适应能今天直接下样。”`
- **定单临门一脚**：
  > `“老板，我们领导在看各厂报价了，就差贵厂这几个明细，麻烦报一下哈，谢谢！”`

## 🔄 三、 规格漂移与变更加价处理模板 (Specification Drift)

> 📌 **触发时机**：当厂家技术人员指出设计瓶颈（如颜色渐变、尺寸浪费、细线条刺绣不清等）并给出修改建议时触发。

### 1. 采纳新工艺并锁定全包报价
- **话术**：
  > `“收到，那我们采纳贵厂建议，统一按【{{SUGGESTED_PROCESS}}】核算。请问按这个新方案：{{ORDER_QTY}}套的大货单价和打样费分别是多少？交期是否有变动？”`

### 2. 尺寸/材质升级加价核算（如改厚度、增电镀、换布底）
- **话术**：
  > `“如果材质厚度从 0.4mm 升级为 0.6mm（已加厚），单价相应增加多少？打样费用是否有变化？”`

### 3. 简化工艺以满足原预算
- **话术**：
  > `“如果取消背卡只保留裸品+独立OPP袋，单价能否做到 {{TARGET_PRICE}} 元以内？交期能压缩到几天？”`

## 🛡️ 四、 反向脱媒防风控话术模板 (Anti-Violation Acquisition)

> 🚫 **红线警示**：1688 聊天框直接输入纯 11 位数字极易触发系统拦截并导致账号降权。

### 1. 首选方案：反向引导留号（方案 B · 零封禁风险）
- **话术 A（索要矢量原图）**：
  > `“老板方便留个绿泡泡吗？我加您把高清AI矢量工程图发过去核对尺寸，咱拉个产品技术群。”`
- **话术 B（沟通打样政策）**：
  > `“老板您留个微或者手机号，我们技术直接加您对接打样文件细节。”`

### 2. 备用方案：汉字微扰发号（方案 C · 当必须我方提供时）
- **格式规范**：禁止使用连续纯数字，采用符号分隔与谐音字混排：
  > `“微电同号：1З8·8888·8888（去掉圆点加我）”`
  > `“VX：abc_138xxxx（备注产品开发）”`

## ❌ 五、 负向熔断与安全退出模板 (Rejection & Clean Exit)

当厂家明确表示无法生产或工期冲突时，礼貌且快速退出，释放真机：

- **厂家做不了**：
  > `“收到，感谢老板回复，后续有其他品类再合作！”`（随后立即执行 `NavigationGuardian.safe_exit_chat()`）
- **交期赶不上**：
  > `“这批货期比较急，这次可能来不及了，下次宽裕点再找您，谢谢！”`
